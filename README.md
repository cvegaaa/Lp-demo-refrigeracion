# Landing de Servicios de Refrigeración

Landing page demo para una empresa de servicios técnicos de refrigeración.

## Qué resuelve

Presenta servicios de instalación y mantenimiento de equipos de refrigeración, con llamada a la acción para solicitar servicio técnico.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS

## Estado

Demo de portafolio.
